## Ask an AI assistant

The site runs a read-only [MCP](https://modelcontextprotocol.io) server (a standard way for an AI assistant to call outside tools), so an AI assistant can look things up in this reading list. It needs no account. The address is `https://ai4ie.org/mcp`.

Its tools are `search_papers`, `get_paper`, `list_applications`, `list_resources` and `get_skill`. In Claude Code, add it with `claude mcp add --transport http ai4ie https://ai4ie.org/mcp`. Other clients take the same address as a remote server. [Privacy](/privacy/) says what the server sends on.
