## Choose where to run the model

Check your data-management plan and institutional policy first.

- **Approved hosted service allowed:** run the model there.
- **Data must stay inside your institution:** ask for an approved workstation or shared server.
- **Data must stay on one device:** run the model locally and check that the tool uses a local endpoint.

## Hardware

The first limit is GPU memory, or unified memory on Apple silicon. A model's size is its
number of parameters (the numbers it learned). Local models are usually stored at reduced
precision: at 4 bits per parameter, the weights take about half a byte per parameter. Leave room for the
context window (the text the model reads at once) and for the runtime. Before you buy
hardware, check your target model with a
[memory estimator](https://huggingface.co/docs/accelerate/usage_guides/model_size_estimator).

<p class="table-title"><b>Table 4.1</b> Weight memory at 4 bits per parameter</p>

| Model size | Approximate weight memory |
|---|---|
| 8 billion parameters | 4 GB |
| 14 billion parameters | 7 GB |
| 30 billion parameters | 15 GB |
| 70 billion parameters | 35 GB |

At 8 bits the weights take about twice this memory, and at 16 bits about four times.
Actual model files can be larger.
