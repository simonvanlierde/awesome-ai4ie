## Choose where to run the model

Check your data-management plan and institutional policy first. If an approved
hosted service can receive the data, you can run the model there. If the data must
stay within your institution, ask about an approved workstation or shared server.
For data that must stay on one device, run the model there and check that the
software uses a local model endpoint.

## Hardware

Start with GPU memory, or unified memory on Apple silicon. At 4 bits per parameter,
the weights alone take about half a byte per parameter. Leave room for the
conversation history and the software running the model. Check the specific
model and settings with a
[memory estimator](https://huggingface.co/docs/accelerate/usage_guides/model_size_estimator)
before buying hardware.

<p class="table-title"><b>Table 4.1</b> Weight memory at 4 bits per parameter</p>

| Model size | Approximate weight memory |
|---|---|
| 8 billion parameters | 4 GB |
| 14 billion parameters | 7 GB |
| 30 billion parameters | 15 GB |
| 70 billion parameters | 35 GB |

At 8 bits, the weights take about twice as much memory. At 16 bits, they take
about four times as much. Actual model files can be larger.
