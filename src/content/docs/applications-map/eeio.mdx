Environmentally extended input-output analysis links trade between sectors to emissions and
resource use. Papers here estimate missing table values, derive emission factors and match
products or firms to sectors.

One study estimates values in next year's input-output tables with deep learning.
It needs that year's row and column totals <Cite id="zhaoUsingDeepLearning2022" />.
Another publishes emission factors
derived from EXIOBASE for use in machine learning <Cite id="guoGlobalEmissionFactor2026" />.
