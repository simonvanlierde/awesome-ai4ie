Most applications here use computer vision to identify, count or measure products and
materials after use. See the [computer vision taxonomy](/applications-map/cv-taxonomy/)
for lab versus field test conditions.

One study estimated the composition of
shredded e-waste from images recorded on a pilot sorting line, with a mean error of 4.94%.
The machine did not sort during the study, so the models ran offline
<Cite id="vogelgesangAutomatedMaterialFlow2025" />. In a washing machine study, software
read the model number in 96% of repair photos and 40% of recycler photos in which a label
was visible <Cite id="sterkensProductLabelIdentification2023" />.
