## Applications by field

Each field has its own page with what works today, every mapped application and its papers.

- <span id="life-cycle-assessment"></span>[Life cycle assessment](/applications-map/lca/): screening impacts, estimating missing inventory values and extracting data from papers.
- <span id="socio-economic-metabolism"></span>[Socio-economic metabolism](/applications-map/sem/): mapping building stocks from imagery and estimating material flows.
- <span id="input-output"></span>[Input-output](/applications-map/eeio/): estimating table values and emission factors.
- <span id="circular-economy"></span>[Circular economy](/applications-map/circular/): computer vision for waste, products and components.
- <span id="industrial-symbiosis"></span>[Industrial symbiosis](/applications-map/symbiosis/): matching one firm's waste to another firm's inputs.
