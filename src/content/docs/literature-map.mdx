Each point is a paper from the [reading list](/literature/). Papers whose title and abstract
read alike sit close together, and the colour and shape of a point give its IE field.
Where a region is empty or a cluster is small, the list is thin. Select a point to open the
paper. The [reading list](/literature/) shows the same map over the list, where its filters
pick which papers stand out.

<LiteratureMap />

The layout comes from text embeddings of each paper's own title and abstract (the abstract comes
from [OpenAlex](https://openalex.org/), and the entry's summary stands in for the few papers
without one), made with the model that powers meaning search. The tags a curator gave a paper are
not an input: they only name the clusters and colour the points, so the map can be checked against
them. The embeddings are reduced to two
dimensions by t-SNE (t-distributed stochastic neighbour embedding) with a fixed seed, so the same
vectors give the same map. The clusters are then found on that 2D layout by k-means, so each one
is a group you can see, and each is named for the tag most over-represented in it compared with
the whole list. Both axes share one scale. t-SNE keeps near neighbours near: a paper's closest
points are its closest papers, but the distance between two clusters means little.
