**Draft for the working group.** This page is not linked from the site yet. I would like your
view on whether it helps before it is.

Each point is a paper from the [reading list](/literature/). Papers whose title and summary
read alike sit close together, and the colour and shape of a point give its IE field.
Where a region is empty or a cluster is small, the list is thin. Select a point to open the
paper.

<LiteratureMap />

The layout comes from the same text embeddings that power meaning search, reduced to two
dimensions by principal component analysis (PCA) and grouped by k-means. Both are
deterministic, so the same list gives the same map. Closeness in the plane is approximate:
PCA keeps the largest differences and flattens the rest.
