<details>
  <summary>Tag IDs and downloads</summary>

  Each tag has a permanent ID you can link to, such as `/vocabulary/#lca`.
  Older reading-list links use the replacement when a tag is retired.
  If there is no replacement, the old filter drops away.

  Read the [YAML source](repo:blob/main/src/data/vocabulary.yaml) or download the
  [SKOS vocabulary](https://www.w3.org/TR/skos-reference/) as [Turtle](/vocabulary.ttl)
  or [JSON-LD](/vocabulary.jsonld).

</details>
