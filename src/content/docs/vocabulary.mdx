These are the tags on the [literature list](/literature/), the [map](/applications-map/) and
the issue forms. Each tag has a permanent id, and each id has an anchor on this page, so
`/vocabulary/#lca` links to life cycle assessment. A retired tag keeps its id, and an old
literature link that uses it shows the tag that replaced it.

The tags live in [`src/data/vocabulary.yaml`](repo:blob/main/src/data/vocabulary.yaml). The
same list is also published as [SKOS](https://www.w3.org/TR/skos-reference/), the W3C format
for vocabularies, in [Turtle](/vocabulary.ttl) and [JSON-LD](/vocabulary.jsonld). Where
Wikidata or OpenAlex has the same concept, or one close to it, the entry links to it.
