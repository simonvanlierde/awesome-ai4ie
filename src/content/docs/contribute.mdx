This site is a proposal to the AI4IE working group. Use the poll or form to add your view.

## Which checks should be IE norms?

Vote for the verification checks you think should become routine practice in AI-assisted industrial
ecology work. Pick as many as you want. The poll keeps totals for each check. See [Privacy](/privacy/)
for what your browser and Cloudflare keep.

## Send a contribution

Use this form without a GitHub account. Your submission becomes a public issue on GitHub.
A maintainer reviews it before including it on the site. Leave the attribution field blank to
omit it from the issue. Keep identifying details out of the text if you want to stay unnamed.

- **Paper, tool, or dataset:** a link and a short note on why it belongs in the guide.
- **Golden question (candidate):** a concrete IE question with a known answer or check. These are
  collected as candidates for group review, not published as a benchmark.
- **AI mistake seen in IE work:** describe what went wrong and how you caught it.
- **Other or comment on an open question:** a correction, a missing topic, or a view on an open
  question.

## Other ways to take part

- **GitHub Issues:** [open an issue directly](repo:issues/new/choose) if you have a GitHub account
  and want notifications when it is reviewed.
- **Pull requests:** edit the YAML data files or pages directly; see
  [CONTRIBUTING.md](repo:blob/main/CONTRIBUTING.md) for the schema and style rules.
- **Discord:** join the working-group channel on [Discord](https://discord.gg/zhHAZakXHX) for
  informal discussion.
