Start here if you're new to using AI in industrial ecology (IE) research. This page says
how reliable AI is on IE tasks today, how to use it well, and which errors to watch for.
To check finished work, use [Verify AI-assisted work](/best-practices/verify/).

## How reliable is AI today?

Two benchmarks test language models on IE tasks. Both found frequent errors.

<p class="table-title"><b>Table 3.1</b> Benchmarks of language models on IE tasks</p>

| Benchmark | What it tests | Headline result |
|---|---|---|
| [Expert-grounded LCA benchmark](https://arxiv.org/abs/2510.19886) (preprint) | 11 general-purpose models on 22 LCA tasks, reviewed by 17 LCA practitioners | Experts found inaccurate or misleading information in 37.2% of responses. Some models invented up to 40% of their citations. |
| [PCFBench](https://arxiv.org/abs/2608.27716) (preprint) | Eight frontier models on 614 expert-labelled items across six product carbon footprint tasks | The strongest models came within a factor of 2 of declared totals on 77% of products. When they built the footprint step by step, that fell to 37–58%, and only 45–75% of those footprints conserved mass. |

<p class="table-src">Source: the abstract of each paper.</p>

An agent is an AI tool that takes steps on its own, such as running code and editing files,
instead of only answering in a chat. Outside IE, agents that try to reproduce published results from the paper's own code and
data still fail most of the time: the best agent scored 21% on the hardest level of
[CORE-Bench](https://arxiv.org/abs/2409.11363). Scores change quickly as models change, so
check a paper's date and the models it tested before you quote a number.

## AI as a research method

- **Start with a baseline.** Compare your model with a simple one, such as linear
  regression. If the gain is small, explain why you need the more complex model.
- **Set the test set aside first.** The test set is data the model never sees in
  training. If you normalize, gap-fill or select features before you split, the model
  learns from the test set and scores too well. This is called leakage. For
  time-ordered data, split by time. Use the
  [ML reproducibility checklist](/best-practices/verify/#machine-learning-reproducibility),
  or [check an existing pipeline for leakage](/best-practices/prompts-and-skills/#data-leakage-self-check).
- **Test where you plan to use the model.** A model trained to estimate building
  age from Toronto street-view photos was less accurate in five other Canadian
  cities. Report where you validated the model.
  [Building-age study](https://doi.org/10.1111/jiec.13591)
- **Compare with independent data.** Local estimates of building stocks ranged from 53%
  to 200% of one global satellite map. Report such differences and say how you estimate
  uncertainty. [Building-stock study](https://doi.org/10.1111/jiec.13585)
- **Check extracted values against the document.** In the
  [inventory studies](/applications-map/lca/), researchers use
  language models to extract values from documents and check them by hand.
  [Try the extraction prompt](/best-practices/prompts-and-skills/#extract-without-inventing).
- **Describe synthetic data.** If you generate data, say how in the methods.

## AI as an assistant

- **Give specific instructions.** Include the schema, units or method constraints
  the assistant needs. Check your data policy before sharing any material.
- **Review small changes.** Read the diff, run tests, and check numerical work on a
  case with a known answer. [AI-assisted coding checklist](/best-practices/verify/#ai-assisted-coding)
- **Get a second review.** Open a fresh session and use the
  [code review prompt](/best-practices/prompts-and-skills/#adversarial-review-of-ai-written-code).
- **Verify claims and citations.** Open the primary source and check what it supports.
  [Source-checking prompt](/best-practices/prompts-and-skills/#verify-a-claim-before-citing-it)
- **Save instructions you reuse.** Put the workflow in a
  [skill file](/best-practices/prompts-and-skills/#agent-skill-files).

For more examples, see the [Prompt Engineering Guide](https://www.promptingguide.ai).

itself doesn't check whether the text is true.

## Pitfalls

- **Invented references.** GPT-3.5 fabricated 55% and GPT-4 fabricated 18% of the
  references they produced in one study ([Walters & Wilder, 2023](https://doi.org/10.1038/s41598-023-41032-5)).
  On LCA questions, some models invented up to 40% ([above](#how-reliable-is-ai-today)).
  Open each reference before citing it.
- **Wrong numbers.** Trace each number you plan to publish to a primary source or
  recalculate it.
- **Confidential data.** A hosted service receives what you send and may keep it.
  Check your data-management plan and institutional policy before sharing anything.
  [Local AI options](/tools/local-ai/)
