# Roadmap

What I plan to work on over the next year. It is a plan, not a promise: the guide currently has one maintainer ([GOVERNANCE.md](GOVERNANCE.md)), and the order changes when contributors open issues or pull requests. Shipped changes are in [CHANGELOG.md](CHANGELOG.md).

Last reviewed: 2026-11-19

## Now

- **Working-group adoption and a second maintainer.** Review the guide with the AI4IE working group, decide whether to move the repository into a shared organisation, and add a second maintainer ([MAINTAINING.md](MAINTAINING.md)).
- **Fill open gaps on the applications map.** Add vetted entries for the fields and techniques listed under "Not mapped yet" as papers and community suggestions arrive.

## Next (12-month horizon)

- **More worked Agent Skills and demos.** Add skills under `skills/` and browser demos only where a workflow holds up on real IE tasks.
- **Keep entries and records current.** Refresh Crossref/arXiv citation records (`pnpm run citations`), recheck tool entries older than a year, and fix broken links surfaced by the weekly link check.
- **Accessibility and test coverage.** Keep zero axe violations across all pages and maintain ≥80% test coverage on `src/`.

## Not planned

- User accounts, logins, server-side storage or analytics.
- Unvetted or AI-summarised entries without a primary source checked by a person.
- Turning the site into a general machine learning textbook outside industrial ecology.

To suggest a paper, application, tool or site change, open an issue. [CONTRIBUTING.md](CONTRIBUTING.md) says how to send a pull request.
