# Roadmap

What I plan to work on over the next year. It is a plan, not a promise. The guide has one maintainer ([GOVERNANCE.md](GOVERNANCE.md)), and the order changes when contributors open issues or pull requests. Shipped changes are in [CHANGELOG.md](CHANGELOG.md), and routine upkeep is in [MAINTAINING.md](MAINTAINING.md#routine).

Last reviewed: 2026-11-19

## Now

- **Working-group adoption and a second maintainer.** Review the guide with the AI4IE working group, decide whether to move the repository into a shared organisation, and add a second maintainer ([MAINTAINING.md](MAINTAINING.md)).
- **Fill open gaps on the applications map.** Add vetted entries for the fields and techniques under "Not mapped yet" as papers and suggestions arrive.

## Next

- **More worked Agent Skills and demos.** Add skills under `skills/` and browser demos only where a workflow holds up on real industrial ecology tasks.
- **Hosting with response headers.** Move deployment so the site can send `Strict-Transport-Security` and response-level Content Security Policy headers.

## Not planned

- User accounts, logins, server-side storage or analytics.
- Entries without a primary source that a person has read.
- Turning the site into a general machine learning textbook outside industrial ecology.

To suggest a paper, application, tool or site change, open an issue. [CONTRIBUTING.md](CONTRIBUTING.md) says how to send a pull request.
